AmpSim is a guitar amp simulator: a Neural Amp Modeler capture, an amp-style front panel, a cabinet and a pedalboard.

This installer is not signed with an Apple Developer certificate. macOS will therefore refuse to open it the first time with “cannot be opened because the developer cannot be verified”, offering only Move to Trash and Cancel.

To let it through, open System Settings → Privacy & Security, scroll to the Security section, and click Open Anyway next to the message about AmpSim. You will be asked to authenticate. Then run the installer again.

On macOS 15 Sequoia and later, control-clicking the file and choosing Open no longer works as a shortcut; the Privacy & Security step is the way.

The alternative, if you prefer the Terminal, is xattr -d com.apple.quarantine /path/to/AmpSim.pkg before opening it.

Nothing here checks who built the software — it only tells macOS you have decided to trust it. Install it only if you trust where you got it from.
